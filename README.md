\# CareerGauge Backend



CareerGauge is a career-readiness platform that helps learners assess their skills, identify skill gaps, and explore career recommendations.



\## Backend



Built with:



\* ASP.NET Core

\* Entity Framework Core

\* PostgreSQL

\* ASP.NET Core Identity

\* JWT authentication

\* REST API

\* xUnit automated tests



\## Projects



\* `CareerGauge.Api` — HTTP API and authentication endpoints

\* `CareerGauge.Application` — application services and DTOs

\* `CareerGauge.Domain` — domain entities and business models

\* `CareerGauge.Infrastructure` — database and persistence

\* `CareerGauge.Tests` — automated tests



\## Main Features



\* Learner registration and authentication

\* Skill profiles and skill-level tracking

\* Career readiness calculation

\* Career recommendations and skill-gap analysis

\* Skill assessments with automatic scoring

\* Authenticated learner ownership

\* Automated backend testing



\## Running Locally



The API runs on:



`http://localhost:5087`



The PostgreSQL connection string is stored using .NET User Secrets and is not committed to the repository.
